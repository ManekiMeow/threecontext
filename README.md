# threecontext
Follow-up work on arXiv:2208.07794 (three-context GHZ paradox, Perkel graph).

* [`RESULTS.md`](RESULTS.md): three-context GHZ graphs (§1–2) and four-context Kochen–Specker sets (§3); code in `search/` and `ks/`.
* [`ks3d/RESULTS.md`](ks3d/RESULTS.md): the smallest Kochen–Specker set in dimension 3; code in `ks3d/`.
* `Perkel/`: the original paper materials (Mathematica notebooks, MATLAB port, data).
